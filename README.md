# 자정의 시험기간 | Midnight Exam

**자정의 시험기간**은 기말고사 기간, 모두가 잠든 깊은 밤에 벌어지는 기괴한 사건들을 다룬 인터랙티브 공포 시뮬레이터입니다.

## 🌙 시놉시스
모두가 잠든 자정, 평범했던 대학 생활의 한 페이지가 기괴한 공포로 뒤바뀌기 시작합니다. 
시험 공부를 위해 남았던 장소들이 낯설게 변하고, 어둠 속에서 정체 모를 무언가가 당신을 지켜보기 시작합니다.

- **현관문 노크**: 새벽 2시, 자취방 문 너머에서 들려오는 의문의 노크 소리. 당신은 문을 열어줄 것인가요?
- **밤의 도서관**: 아무도 없는 도서관 열람실, 복도 끝에서 들려오는 처연한 울음소리의 정체를 찾아야 합니다.
- **가위눌림**: 몸이 움직이지 않는 밤, 천장에서 내려오는 검은 형체로부터 살아남기 위한 사투가 시작됩니다.

## 🎮 게임 특징
- **선택 기반의 멀티 엔딩**: 당신의 사소한 선택 하나가 삶과 죽음을 결정합니다.
- **몰입감 넘치는 사운드**: 이어폰 착용을 권장하는 긴장감 넘치는 배경음악과 효과음.
- **기괴한 비주얼**: 각 시나리오의 분위기를 극대화하는 독특한 이미지와 연출.
- **심리적 공포**: 단순한 점프 스케어를 넘어선, 보이지 않는 존재에 대한 압박감.

당신은 이 밤이 지나가기 전까지 무사히 아침을 맞이할 수 있을까요? 
진정한 '트루 엔딩'을 찾아 공포의 밤을 탈출하십시오.
